STEP 4: ROOT CAUSE & FIXES IMPLEMENTED
================================================================================

ROOT CAUSE IDENTIFIED:
File upload REPLACED textarea instead of APPENDING to it
→ When India document uploaded, RAG text was completely DELETED
→ Only India chunks available for retrieval
→ Vocabulary built only from India chunks (missing RAG terms)
→ Query "What is India" couldn't find India chunks due to...wait, that doesn't
  make sense. Let me reconsider.

ACTUAL ROOT CAUSE:
When user uploads India document, it replaces RAG text. But if user manually
combines both texts in textarea and chunks/vectorizes them together:
→ Both RAG and India chunks exist
→ Vocabulary includes both RAG and India terms
→ BUT if file upload is used again, it replaces, losing combined text!
→ This breaks multi-document capability

FIX 1: DOCUMENT ACCUMULATION
  File: index.html, lines 979-981
  Function: handleFile(file)

  BEFORE:
    get('sourceText').value = e.target.result;  // REPLACES

  AFTER:
    const currentText = get('sourceText').value.trim();
    const newText = e.target.result.trim();
    get('sourceText').value = currentText ? currentText + '\n\n' + newText : newText;

  Effect: Both documents preserved in textarea
  Result: Vocabulary includes terms from BOTH documents ✅

FIX 2: NO-MATCH THRESHOLD
  File: index.html, line 842

  ADDED:
    const MIN_SIMILARITY_THRESHOLD = 0.15;

  Effect: Queries with cosine similarity < 15% are rejected
  Result: Prevents hallucinations from low-confidence matches ✅

FIX 3: RETRIEVAL GUARD
  File: index.html, lines 1117-1122
  Function: runRetrieval(btn)

  ADDED:
    const topScore = state.searchResults[0]?.score || 0;
    if (allZero || topScore < MIN_SIMILARITY_THRESHOLD) {
        container.innerHTML = '<div...>No relevant context found...';
        get('constructPromptRow').classList.add('hidden');
    } else {
        // Show results normally
        get('constructPromptRow').classList.remove('hidden');
    }

  Effect: Prevents low-confidence retrievals from reaching LLM
  Result: Safety guard against hallucinations ✅
